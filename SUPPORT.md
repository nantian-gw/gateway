# Support

Use English or Chinese when opening an issue — both are welcome.

## Where to Start

- Build, test, or contribution questions: [CONTRIBUTING.md](CONTRIBUTING.md)
- Development workflow and validation strategy: [docs/development.md](docs/development.md)
- Local run, Kind quick start, and admin API usage: [docs/user/getting-started.md](docs/user/getting-started.md)

## Which Issue Form to Use

- **Bug Report**: For runtime, build, test, deployment, or documentation defects.
- **Feature Request**: For new capabilities, API changes, or infrastructure improvements.
- **Question**: For usage, debugging, architecture, or troubleshooting questions.

Security-sensitive reports should follow [SECURITY.md](SECURITY.md) and be reported privately rather than in a public issue.

## What to Include

- Affected area
- Exact command or request
- Expected behavior and actual behavior
- Environment details
- Minimal logs or config snippets (where necessary)

Do not include secrets, tokens, certificates, or private keys.
