# 4. Performance Testing Environment Recommendations

To make results comparable, recommend fixing these:

## 1) Environment Fixation
- Fixed node specifications
- Fixed replica count
- Do not auto-scale during load testing, or record HPA behavior
- Backend should use stable response logic as much as possible, to avoid mistaking business jitter for gateway jitter

## 2) Load Testing Tool Recommendations
Choose by protocol:

- HTTP/HTTPS: `fortio` / `wrk2` / `vegeta`
- HTTP/2: `h2load`
- gRPC: `ghz`
- WebSocket: `websocat` or custom load test program

## 3) Metrics That Must Be Collected
### Data Plane
- QPS / RPS
- success rate / error rate
- p50 / p90 / p99 / p999
- CPU / Memory
- FD
- active connections
- TLS handshake latency
- upstream connect latency
- retry rate
- pool hit ratio

### Control Plane
- reconcile latency
- queue depth
- error rate
- status update latency
- config propagation latency
